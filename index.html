Overall Reflection

จาก A1 มาสู่ A2

จาก A1 ผมเริ่มจากเว็บไซต์ที่มีโครงสร้างไม่ซับซ้อนและใช้ CSS พื้นฐาน ใน A2 ผมได้ปรับแนวคิดการออกแบบให้เป็น responsive มากขึ้น โดยใช้ Bootstrap Grid แบ่งคอลัมน์ ใช้ Flexbox จัดแนว navigation และใช้ utility classes ช่วยเรื่อง spacing กับ sizing

สิ่งที่สำคัญคือการทดสอบหลายขนาดหน้าจอ ไม่ใช่แค่ทำให้หน้าเว็บดูดีบนคอมพิวเตอร์เท่านั้น ผมจึงออกแบบให้ส่วน hero และ portfolio เปลี่ยนจากหลายคอลัมน์เป็นคอลัมน์เดียวบนหน้าจอเล็ก เพื่อให้อ่านง่ายและไม่ต้องเลื่อนในแนวนอน

ขั้นต่อไป ผมอยากฝึกใช้ Git/GitHub ให้เป็นระบบมากขึ้น โดยสร้าง Issue ก่อนลงมือแก้ไข ทดสอบงานก่อน commit และเขียน commit message ให้บอกได้ชัดเจนว่าแต่ละรอบเปลี่ยนอะไร
